# What's New in Version 1.3.4

**Released:** November 17, 2026

---

## 🐛 Bug Fixes

### Hosting and catalog purchases stay off RMM

Windows Server Hosting and other catalog products now get a Cloudigan purchase confirmation. They no longer create a Datto RMM site or send an RMM agent email.

**What changed:**
- Hosting purchases send a hosting confirmation
- Known catalog products are matched by Stripe product ID
- RMM subscriptions still create a Datto site and send the agent download email
